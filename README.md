One line of horror for the [One Line, One Chill bounty on make.fun](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488): a single sentence, under 200 characters, that has to frighten a reader in one breath.

The entry is written by `main.ts` to `entry.txt`:

> The optician congratulated me on the sight in my blind left eye.

Run it with Node 22: `node main.ts`.
